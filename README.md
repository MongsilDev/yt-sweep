# YT Sweep

유튜브 홈, 검색, 추천, 쇼츠에서 AI 양산 채널과 불펌, 클립 채널을 가려내는 브라우저 확장입니다.
채널 정보와 최근 영상으로 점수를 매기고 점수에 따라 표시하거나 숨기거나 채널 추천 안함을 보냅니다.
판정은 브라우저 안에서만 하고 외부 서버나 LLM은 쓰지 않습니다.

## 무엇을 잡나

- 채널 설명에 AI 음성, AI 제작을 밝혀 둔 채널
- 유튜브가 공식 AI 표시를 붙인 영상을 올리는 채널
- 원본 출처, 공정 이용 같은 재업로드 면책 문구를 단 채널
- 영상 설명이 남의 채널 핸들이나 출처 줄뿐인 채널
- 가입한 지 얼마 안 됐는데 영상을 빠르게 쌓는 채널
- 구독자 1,000명 미만 채널

구독 중인 채널은 건드리지 않습니다.
채널이 대상이 아니어도 공식 AI 표시가 붙은 쇼츠는 그 영상만 처리합니다.

## 설치

스토어에 올리지 않았기 때문에 폴더를 직접 불러와야 합니다.

1. 이 저장소를 내려받습니다.
2. 확장 관리 페이지를 엽니다. 크롬은 `chrome://extensions`, 엣지는 `edge://extensions`, 웨일은 `whale://extensions`입니다.
3. 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램 로드를 눌러 이 폴더를 고릅니다. 버튼 이름은 크롬 기준입니다.
5. 유튜브를 새로고침하면 화면 왼쪽 아래에 버튼이 생깁니다.

## 사용법

왼쪽 아래 버튼을 누르면 패널이 열립니다. 모드는 세 가지입니다.

| 모드 | 동작 |
|---|---|
| 표시만 | 대상 카드에 테두리와 점수, 걸린 이유를 붙입니다. 처음 설치하면 이 모드입니다. |
| 숨김 | 대상 카드를 숨깁니다. |
| 숨김과 추천 안함 | 숨기고, 채널에는 채널 추천 안함을, AI 표시 영상에는 관심 없음을 보냅니다. |

패널에는 찾은 채널과 기준에 조금 못 미친 채널이 점수와 함께 나옵니다.
채널마다 추천 안함과 허용을 따로 누를 수 있고, 허용한 채널은 허용 목록에서 취소할 수 있습니다.
추천 안함을 보낸 채널은 최근 30개가 패널에 남고, 거기서 되돌릴 수 있습니다.
추천 안함은 5초에 한 번, 하루 200개까지만 보냅니다.

숨김과 추천 안함은 표시만으로 며칠 써 보고, 엉뚱한 채널이 걸리지 않는지 확인한 다음 켜는 것을 권합니다.

## 점수

6점 이상이면 대상입니다.

| 신호 | 점수 |
|---|---|
| 최근 영상 두 개 모두 공식 AI 표시 / 하나만 | +6 / +3 |
| 채널 설명의 AI 제작 고지 | +6 |
| 재업로드 면책 문구 | +6 |
| 영상 설명이 출처 표기뿐이고 본인 방송, 연락처 안내가 없음 | +6 |
| 쿠팡 파트너스 링크 | +4 |
| 구독자 1,000명 미만 / 5,000명 미만 | +6 / +2 |
| 쇼츠만 10개 넘게 올림 / 그 밖에 링크와 운영자 정보 없음 | +6 / +2 |
| 평균 30분 이상 영상을 하루 3개 이상 / 평균 20분 이상 영상을 하루 1.5개 이상 | +6 / +4 |
| 가입 뒤 하루 평균 3개 이상 / 0.3개 이상 업로드 | +6 / +4 |
| 유튜브가 자동으로 만든 형태의 핸들 | +1 |

구독자 30만 명 이상이고 가입한 지 5년이 넘은 채널은 업로드 속도 점수를 받지 않습니다.
무단 전재 금지처럼 자기 콘텐츠를 지키는 문장에 들어간 AI, 출처 문구는 고지로 세지 않습니다.
키워드와 기준은 전부 `classifier.js`에 있습니다. 취향에 맞게 고쳐 쓰면 됩니다.

## 한계

- 구독자 1,000명 미만이면 그것만으로 대상이 됩니다. 작은 사람 채널도 함께 걸립니다.
- 채널 하나를 판정할 때 유튜브에 4번에서 6번 요청을 보내고, 결과는 14일 동안 저장합니다.
- 유튜브 화면의 내부 구조를 읽어서 동작합니다. 유튜브가 구조를 바꾸면 멈추고, 그때는 패널에 안내가 뜹니다.

## 주의

- 추천 안함은 유튜브 내부 API로 보냅니다. 유튜브의 자동화 규정에 어긋날 수 있습니다. 쓰는 사람이 책임져야 합니다.
- 설정과 판정 기록은 브라우저의 youtube.com 저장소에만 남습니다.
